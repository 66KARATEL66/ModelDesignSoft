# Anime Figurine Store

Навчальна система автоматизації магазину аніме-фігурок, реалізована на .NET 8. Проєкт охоплює предметну модель, реляційні зв'язки, репозиторії, сервіси, прецеденти, документи вимог, стани замовлення, послідовності викликів, пакети, класи та розгортання.

## Технології

- C# / .NET 8;
- консольний застосунок;
- сховище даних у пам'яті;
- PlantUML для UML-діаграм;
- DBML для реляційної моделі;
- openpyxl для створення `.xlsx` документів.

## Запуск

```powershell
dotnet run --project "lb1/lb1/lb1.csproj"
```

Перевірка збірки:

```powershell
dotnet build "lb1/lb1/lb1.csproj"
```

## Структура

- `lb1/lb1/Models` — сутності предметної області;
- `lb1/lb1/Data` — сховище та репозиторій;
- `lb1/lb1/Services` — сервіс виведення та сервіс замовлень;
- `Lab_01`–`Lab_09` — матеріали лабораторних робіт;
- кожна лабораторна розділена на змістовні папки завдань, а сутності розміщені окремо всередині відповідних папок;
- `lb1/lb1/Scripts/AllLabsRunner.cs` — скрипти послідовного виведення результатів усіх лабораторних у `Program.cs`;
- `ALL_LABS_REPORT.md` — послідовний огляд усіх виконаних лабораторних;
- `PROJECT_AUDIT.md` — аудит початкової та поточної реалізації;
- `PROGRESS.md` — стан усіх завдань;
- `FINAL_SUMMARY.md` — підсумок виконання.
